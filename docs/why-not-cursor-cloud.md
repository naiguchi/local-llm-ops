# なぜ Claude / Cursor クラウドを使わないか

## 問題

Claude や Cursor（クラウドモデル・Cloud Agent）に本番接続・SQL・ログを渡すと、次が外部に出うる。

- プロンプト本文（スキーマ、症状、SQL、結果の一部）
- ツール呼び出しの入出力
- 一部製品のテレメトリ・履歴

運用・本番作業ではこれが許容できない。

## このリポジトリでの代替

| 作業 | 使うもの |
| --- | --- |
| 通常のアプリ開発（機密を載せない） | Cursor / Claude 可 |
| 本番接続・運用 SQL・本番ログを含む作業 | **local-llm-ops のみ**（Ollama + 承認付きスクリプト） |

## 注意

Cursor を「ローカルモデル接続」だけで使う場合でも、製品側がクラウドに送る経路がないか都度確認すること。  
不安なら **Cursor を開かず**、Open WebUI と `agent/tools` だけを使う。
